Inventory Items and conversions

Nothing here is fixed — edit any ratio, or add a brand new raw material or prepared item.

Add new raw material

Calls POST /api/v1/inventory-items with type = raw_material

Drag and drop or Choose File JPEG, PNG, WEBP formats, up to 50MB

Add new prepared item (with its own conversion)

Calls POST /api/v1/inventory-items with type = prepared, linking raw material ratio

Drag and drop or Choose File JPEG, PNG, WEBP formats, up to 50MB

Add stock

Log a new raw material purchase, convert it into prepared items, then distribute to branches.

Stock raw material

Calls POST /api/v1/inventory-transactions with transaction_type: 'purchase'

Convert to prepared item

Ratios come from the "Items and conversions" page — calls POST /api/v1/stock-conversions/convert

Distribute to branch

Calls POST /api/v1/inventory-items/{id}/distribute to sync branch inventory levels
